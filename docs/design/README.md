# Euraika Compass UI concepts

These images were generated with the built-in image generation tool as design explorations. They are not screenshots of a running application. Example source links, text, translations, and language-analysis labels illustrate the proposed interface and have not been validated as application results. No religious preference is implied by the selected sample passages.

The first direction used warm ivory, forest green, and sage. Version 2 responds to a request for livelier colors: petrol navigation, turquoise interactions, amber highlights, white reading panels, and a pale ice background. The original generated images are retained locally outside this repository; the current concept images are included here.

## Design principles

- A persona selector changes conversation style, not religious preference.
- Source collections have equal visual weight; color is not a ranking of religions.
- Published translations and generated paraphrases must be identified explicitly in the implemented app.
- Real linguistic annotations will need their own named annotation source; the mockup label is illustrative.
- Typography, contrast, right-to-left text, keyboard navigation, and responsive layouts still need implementation and live testing.

## Generation prompts

Tool: built-in `image_gen`, opaque background. Each initial screen was generated independently; the color revision edited the corresponding initial image while preserving its content and layout.

### Color revision applied to all three screens

```text
Edit target: the attached Euraika Compass UI screenshot. Use case: ui-mockup color revision. Preserve the exact screen, Dutch text, layout, panel positions, type scale, readable Greek where present, controls and all information. Change only the visual color treatment to be noticeably more lively, crisp, contemporary and optimistic, while staying tasteful and readable for serious research and sensitive conversations.
Replace muted beige/olive/forest palette with a richer fresh palette: saturated deep petrol #075B6B for navigation and key headings; bright turquoise #10B9AE for selected controls, active accents, tiny icons and interaction highlights; warm golden amber #F2B544 for compass mark, delicate highlights and small focus accents. Use pale ice #F0F8FA page background and clean white content cards with thin blue-grey borders, charcoal/navy body text #17323D. Give the left navigation a rich petrol background and light text, active item a bright turquoise treatment with dark readable lettering. Use a warm pale amber highlight for selected words or the thoughtful reflection callout, turquoise-tinted user chat bubble if present. Buttons in vibrant petrol/turquoise with strong contrast. Slightly richer depth from restrained shadows, no heavy gradients, no dark mode, no neon, no purple default AI aesthetic, no photographic elements.
All three religious collections must retain EXACTLY the same visual prominence and identical heading/accent treatment: never assign one religion a special color, winner badge, or more attention. Preserve tiny "Ontwerpconcept" label. Maintain high-fidelity full-screen screenshot dimensions and polished editorial typography. This should feel clearly more colorful than the original, not just a tiny saturation adjustment. Do not change wording or invent extra content.
```
